폰 연락처 앱에서 1분이면 돼요
백업 파일(VCF)이 뭐예요?
  • 연락처 전체를 담은 파일 한 개예요
  • 만드는 순간 그 자체가 안전한 백업이 돼요
  • 이 파일을 열어 정리 후보를 찾아드려요
1
폰 연락처 앱 열기
폰의 기본 연락처(전화번호부) 앱을 열어요.
2
연락처 관리 들어가기
연락처 화면에서 메뉴(≡)를 누르고 → 연락처 관리를 눌러요.
3
내보내기 하기
연락처 가져오기 또는 내보내기 → 내보내기 → 내장 메모리를 선택해요. 그러면 연락처.vcf 파일이 만들어져요.
4
그 파일 열기
아래 버튼을 눌러 방금 만든 .vcf 파일을 선택하면 끝!
아이폰: 연락처 앱에서 연락처 선택 → 공유로 파일을 만들어요.
왜 이 방식인가요?
앱이 연락처에 직접 손대지 않으니 가장 안전해요. 게다가 내보내기한 파일이 곧 백업이라, 정리 전에 보험부터 드는 셈이에요.

이 앱이 지키는 약속
  • 백업 파일을 읽기만 해요 (폰 연락처는 안 건드림)
  • 서버 전송 없음 — 모든 처리는 내 폰 안에서만
  • 정리 대상만 찾아서 보여드려요
  • 실제 정리는 폰 연락처 앱에서 직접 하세요
어떻게 쓰나요?
항목을 눌러 들어가서, 지울 번호에 [삭제]를 누르세요. 원본 파일은 그대로 두고, 삭제 표시한 번호만 뺀 새 파일을 만들어 드려요. 새 폰엔 그 파일로 가져오면 깔끔하게 이사 끝!

개의 연락처
어떻게 백업되나요?
  • 열었던 파일 그대로가 이미 백업이에요
  • 여기서 새 백업 파일을 한 번 더 만들 수도 있어요
  • 일반 공유로 카톡·메일·드라이브에 보낼 수 있어요
  • 파일을 우리가 보관하지 않아요 (내가 보낸 곳에만)
  • 폰 바꾸면 그 파일로 연락처를 복원할 수 있어요
파일 이름 .vcf

저장하면 파일 앱 → 다운로드에 담겨요.
카톡 전송: 카톡에서 ＋ → 파일 → 다운로드에서 선택하면 확실해요!

복원은 어떻게 하나요?
아래 복원 탭에서 방법을 확인하세요. 백업해둔 VCF 파일만 있으면 새 폰에서도 몇 번의 탭으로 연락처를 되살릴 수 있어요.
연락처 복원
새 폰에서 되살리기
백업 파일로 복원하기
  • 이 앱은 길만 안내해요 — 복원은 폰이 직접 해요
  • 정리해 저장한 VCF 파일만 있으면 돼요
1
정리된 파일 준비
이 앱에서 저장한 파일은 내 파일 → 내장 메모리 → Download 폴더에 있어요. 카톡·드라이브로 받았어도 같은 폴더예요.
2
연락처 관리 들어가기
연락처 앱 → 메뉴(≡) → 연락처 관리 → 연락처 가져오기 또는 내보내기 → 가져오기를 눌러요.
3
파일 위치 고르기
내장 메모리를 선택하고, Download 폴더의 정리된 파일(연락처_정리.vcf)을 골라요.
4
저장 위치 선택 → 가져오기
연락처를 저장할 곳(휴대전화 또는 구글·삼성 계정)을 고르고 가져오기를 누르면, 연락처가 되살아나요!
왜 앱이 직접 복원 안 하나요?
연락처에 쓰는 건 위험할 수 있어서, 안전하게 폰 기본 앱에 맡겨요. 우린 파일을 만들고 길을 안내할 뿐, 아무것도 직접 건드리지 않아요.
